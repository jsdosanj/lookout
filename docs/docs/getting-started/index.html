Getting started

This guide takes you from nothing to your first server on the dashboard. If you can paste a command into a terminal, you can do this.

What you’ll set up

  • The control plane — the dashboard that collects reports. You run one of these.
  • The agent — a tiny program you put on each server you want to watch.

1. Get the code

Lookout is open source. You need Go 1.26+ to build it (a one-line install is coming).

git clone https://github.com/jsdosanj/lookout.git
cd lookout

2. Start the control plane

Pick a secret token — agents use it to prove they’re allowed to report.

go build -o lookout-server ./cmd/lookout-server
LOOKOUT_TOKEN=choose-a-long-secret ./lookout-server

The dashboard is now at http://localhost:8080. It’s empty until a server reports in.

3. Run the agent

On the same machine (to try it) or any server you want to watch:

go build -o lookout-agent ./cmd/lookout-agent
./lookout-agent run --server http://localhost:8080 --token choose-a-long-secret --once

Refresh the dashboard — your server is there, with its status, memory, disk, and services.

4. Keep it reporting

Drop --once to have the agent report continuously (every minute by default):

./lookout-agent run --server http://localhost:8080 --token choose-a-long-secret

In production you’d install the agent as a service so it starts on boot — see Install the agent.

Just want to look first?

You can also collect a report without a server, to see exactly what the agent gathers:

./lookout-agent report

Next steps

  • Install the agent on Linux, Windows, or macOS as a service.
  • Self-host the control plane for your whole team.
  • Set up alerts so you’re told before something breaks.
