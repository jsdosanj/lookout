Documentation

Lookout is commercial IT infrastructure monitoring. You install a small agent on each server and connect it to a control plane — hosted by us, or deployed on-prem — that collects reports and shows a plain-English health dashboard. This documentation takes you from install to alerting to writing your own checks — no security background required.
