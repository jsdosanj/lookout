One tiny agent

A single dependency-free binary on each server. Outbound-only — no open ports, no agents to babysit.

◆

Plain-English health

Every server reads ok / warning / critical with the reason spelled out — “disk /data is 94% full” — not a wall of metrics.

Bring your own checks

Alerts that matter

Managed or on-prem
