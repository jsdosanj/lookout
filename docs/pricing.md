# Lookout pricing

Lookout is **open source (AGPL-3.0)**. Self-host the entire platform — unlimited
hosts, every feature — for free, forever. The paid plans are **managed hosting**:
we run the control plane so you don't have to. Hosted plans are priced by the
number of **hosts** (servers) you monitor.

> These are a starting model — validate against real sales conversations and
> adjust. Annual billing saves ~20%.
