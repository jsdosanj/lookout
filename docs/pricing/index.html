Pricing questions

Is self-hosting really free?

Yes. Lookout is open source under AGPL-3.0 — run the agent and the control plane on your own infrastructure, for unlimited hosts, at no cost, forever. You only pay if you want us to host and manage it for you.

What counts as a “host”?

Any server (or VM) you run the agent on. Hosted plans are priced by the number of hosts you monitor; self-hosting has no limit.

Do cheaper plans lose features?

Every plan — including free self-hosting — includes all checks, plugins, the dashboard, and alerts. Higher hosted plans add scale, SSO/RBAC, and support.

Do you offer MSP / partner pricing?

Yes. If you monitor fleets for multiple clients, we price per managed client organization with volume discounts, plus an optional white-label. Mention your client count when you contact us.
